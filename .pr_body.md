# Static Analysis - Code Quality Improvements

## Summary

Static analysis of the codebase found several meaningful issues:

## Bug Fixes

### 1. ShoppingList.sharedMemberCount returns incorrect values

Previously used simple subtraction (`memberCount - 1`), which fails when the owner isn't in the members list (e.g., during Firestore corruption or migration). Now uses proper filtering to count only non-owner members.

### 2. ShoppingItem.fromJson crashes on missing fields

Used `DateTime.parse()` which throws when fields are null or missing. Replaced with safe `DateTime.tryParse()` fallback to `DateTime.now()`, consistent with the existing `fromJsonSafe` method.

### 3. Unnecessary Future.value() wrappers

Three validation checks in ListDetailViewModel wrapped synchronous `_fail()` calls in `Future.value()`, creating unnecessary Future completions. Replaced with direct `_fail()` calls.

## Files Changed

- `app/lib/models/shopping_list_model.dart` - Fix sharedMemberCount logic
- `app/lib/models/shopping_item_model.dart` - Safe DateTime parsing in fromJson
- `app/lib/screens/list_detail/view_models/list_detail_view_model.dart` - Remove Future.value() wrappers
