## Problem

When migrating local lists to Firebase, the code subscribed to a broadcast
stream via `watchList()` and called `firstWhere` to check if a list already
exists in the cloud.

This hangs indefinitely when the list doesn't exist because:
1. `watchList()` returns a broadcast stream that only emits when the list
   document changes
2. If the document doesn't exist, no listen is set up on the Firestore side,
   so no emission ever occurs
3. `firstWhere` waits for a value that will never come

## Solution

Replace the stream-based approach with a direct Firestore document query
using `doc.get()`, which immediately returns the document state (exists or
not).

This is also faster (no stream setup/teardown) and more correct for a
one-time existence check.
